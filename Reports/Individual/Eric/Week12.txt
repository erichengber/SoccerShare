Reflection and Lessons Learned:
● This week reinforced how important it is to think about onboarding as a full system rather
than a single screen. Building the pages themselves was only one part of the process,
since the routing logic, default test data, authentication state, and database schema all
had to work together for the user experience to feel correct. I also learned that
supporting multiple roles adds complexity quickly, especially when each role has
different required setup data and onboarding conditions. Overall, this experience showed
the value of end-to-end testing, consistent design patterns, and aligning frontend logic
closely with the database structure.
